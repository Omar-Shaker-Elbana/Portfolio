PROJECT 03

Linear Regression from Scratch

Completed

Implemented three regression algorithms from mathematical first principles — no ML libraries, just NumPy and matrix calculus. Results achieve machine-precision agreement with scikit-learn at under 1e-13 error. Trained on a Canadian vehicle CO₂ emissions dataset.

  • Normal Equation from matrix calculus — (XᵀX)⁻¹Xᵀy from scratch
  • Gradient Descent converging to optimal weights at Δ < 1e-3
  • Ridge Regularization across λ = 0 → 100 with bias-variance analysis
  • MSE ≈ 913 · R² ≈ 0.734 · <1e-13 error vs scikit-learn

PROJECT 04

Dijkstra's Algorithm

Completed

A clean, production-ready implementation of Dijkstra's shortest path algorithm built from scratch in Python — no library calls, just a custom Graph class, a min-heap priority queue, and path reconstruction logic. Stress-tested on a 17-node graph with cycles, zero-weight edges, and disconnected components.

  • Custom Graph class — adjacency list, add/remove vertex & edge, vertex renaming
  • O((V + E) log V) via binary heap — handles 0-weight edges and unreachable nodes
  • Path reconstruction with full route tracing back to source
  • 17-node stress-test graph with cycles, traps, chords, disconnected island

PROJECT 06

Vault Protection System

Completed

A PIN-authenticated vault access system built on Arduino, simulated in Tinkercad and rebuilt on real hardware. Four push buttons set the 4-digit code by press-count, an I2C LCD tracks entry live, and a strict 3-trial lockout drives a buzzer alarm on repeated failed attempts.

  • Press-count digit entry — each press increments 0→9, rolls over, hold-to-repeat
  • Edge-detected button reads with debounced state tracking across 5 inputs
  • 3-trial lockout — red LED + buzzer alarm on repeated failures
  • 16x2 I2C LCD — live PIN entry, Accepted/Rejected/Alarm status
  • Designed & simulated in Tinkercad before hardware implementation

PROJECT 07

Video Games & Mental Well-Being

Completed

A research report for SM101 (Critical Thinking & Scientific Method) investigating whether video game usage causes depression indicators. Designed and iterated a questionnaire, collected 67 responses, and analyzed the data against the stated hypothesis.

  • 67 respondents surveyed via WhatsApp, LinkedIn & Instagram
  • Questionnaire redesigned after instructor feedback — fixed cornering & assumption-based questions
  • 8 questions — Yes/No, checklist, multiple-choice & scale formats
  • Hypothesis rejected: no strong causal link found between gaming & depression
  • Proposed follow-up hypothesis: academic load causes depression
